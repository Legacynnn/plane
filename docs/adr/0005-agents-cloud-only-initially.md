# Agents ship cloud-only at first

The IA module's agents, the Slack triggers and the Jev enrichment are switched off on self-hosted instances until the runtime, credits and provider setup are stable enough to hand to operators. Cloud credits are sold through Dodo Payments. The credits ledger is still built to be edition-agnostic (ADR 0003), so enabling self-host later means switching a flag and adding operator setup, not a redesign.
